# そらのみなと（試作）

小さな地方空港をハブ空港に育てる経営シミュレーション。iPhone のホーム画面に追加すれば機内モードでも遊べます。
素の HTML / CSS / JavaScript だけで、外部通信はしません。

## 遊び方

- 空港は 6:00〜24:00 に動く（等速で1日 約2分。×2・×4 で早送り）。
- **航空会社**と契約すると便が来る。着陸料が入り、ゲートに止まっているあいだ旅客がターミナルを通る。
- **ターミナルのつくり**（空港側から道路側へ）：ゲート待合室 → 出発エリア（お店・ラウンジ・免税店）→ 保安検査場・出入国審査・手荷物受取場 → 一般ロビー（チェックイン）→ 車寄せ。
- **出発客**：車寄せ → 自分の航空会社のチェックインカウンター（なければ共用カウンター・自動チェックイン機）→ 保安検査 →（国際線は出国審査）→ 出発エリア → 待合室 → 搭乗橋。
- **到着客**：搭乗橋 → 待合室 →（国際線は入国審査）→ 手荷物受取場 → 一般ロビー → 車寄せ。
- チェックイン・保安検査・手荷物受取・出入国審査は、それぞれ1時間にさばける人数が決まっている。足りない段階で行列ができ、評判と買い物が減る。
- 専用カウンターは航空会社から1日 ¥60 の賃料が入る。
- 出発エリアのお店は、客がゆっくりするので売上+30%。お店は隣に置くもので売上が変わる。
- ターミナルは左右に2回まで増築でき、そのたびにゲートと各区画が広がる。駐車場（平面 → 2層 → 4層）・空港駅（高架）・空港ホテルはターミナルの外に建てる。
- 1日の旅客数と評判でランクが上がる：地方空港 → にぎわう空港 → 拠点空港 → 国際空港（出入国審査が必要）→ ハブ空港。
- 旧版のセーブは、建物の代金を全額返して新しいターミナルに引き継ぐ。

## iPhone に入れる（機内モードで遊ぶには https が必要）

オフライン起動は service worker で行うため、**https で配信したページ**からホーム画面に追加したときだけ有効になります。
Mac の `python3 -m http.server` を `http://192.168.x.x:8731` で開く方法は、同じ Wi-Fi のあいだは遊べますが、機内モードでは起動しません。

おすすめはルートランナーと同じ **GitHub Pages**（手順は `../lootrunner-prototype/README.md` の「GitHub Pages で公開する」と同じ。リポジトリ名だけ変える）。

1. このフォルダの中身を GitHub のリポジトリに上げ、Settings → Pages で公開する。
2. iPhone の Safari で `https://<ユーザー名>.github.io/<リポジトリ名>/` を開き、「ホーム画面に追加」。
3. ホーム画面のアイコンから一度起動する（ここでファイルが iPhone に保存される）。設定画面の「オフライン」が「有効」になっていれば、機内モードでも起動できる。

## 開発メモ

- セーブは localStorage（`soranominato-v1`）。1ゲーム時間ごと・建てたとき・閉じたときに保存。
- 絵はすべてコードで作った斜め見下ろしのドット絵。飛行機・施設・車は小さな立方体（ボクセル）の模型として組み（`Vox`・`FACMODEL`・`planeModel`）、`renderVox` で描く。地面の標示は `groundColor` がボクセル1つずつの色を決める。
- 地図は画面いっぱい。ドラッグで移動、2本指（マウスはホイール）か右の ＋／－ で拡大縮小。お客さんの歩く姿と道路の車は見た目だけで、セーブしない。
- localhost で開いたときは古い版が残らないよう service worker を使わない（`?sw` を付けると使う）。
- デバッグ用に `window.T`（状態 `T.S`、`T.step(分)`、`T.day()` など）。
- バランス確認：ブラウザのコンソールで `(await import('./tools/bot.js')).runBot(40)`。セーブを上書きします。
  いまの最短ペース（自動プレイ）：にぎわう空港 3日目・拠点空港 8日目・国際空港 18日目。
